# Install a generated Traefik certificate

Use the admitted Deployment subject, sorted exact route hosts, the complete
prior certificate snapshot, the original issuer child as revision ID, and the
expected leaf fingerprint and content digest. The two mounted file-secret files
are the only certificate inputs. A local refusal touches no Server and emits no
observation. Simulation ends without a consumed result.

The shared selection owner compares the prior snapshot, quiesces the subject's
timer, selects the already-issued pair as automatic material (null material ID,
exact revision), and probes local SNI with system trust. It never enrolls a
native renewal unit on success or invokes lego. Failure-only restoration may
restore genuinely observed prior automatic enrollment after a rolled-back
switch; that is not enrollment of the generated certificate.

The backend must require the exact revision, fingerprint and selected hosts,
one binding, matched and trusted SNI for each host, and inactive/disabled
renewal independently of task exit. Missing output is not success. The record
does not establish public DNS or serving beyond the observed local listener.
